# WebAHC - Asociación Histórica de Cuzcurrita

Web de la Asociación Histórica de Cuzcurrita (A.H.C.), dedicada al estudio y documentación de la historia de la Villa de Cozcurrita de Río Tirón, así como de su patrimonio cultural y arquitectónico.

## 📋 Características

- ✨ Diseño limpio y elegante en blanco, negro y azul marino
- 📱 Totalmente responsivo (adaptado a todos los dispositivos)
- 🖼️ Dos galerías dedicadas a Patrimonio Cultural y Arquitectónico
- 📧 Información de contacto
- 🏛️ Secciones informativas sobre la asociación
- ⚡ Navegación suave y fluida

## 🚀 Instalación

1. Clonar el repositorio:
```bash
git clone https://github.com/asociacionhistoricacuzcurrita/WebAHC.git
```

2. Navegar al directorio:
```bash
cd WebAHC
```

3. Abrir `index.html` en el navegador o desplegar en GitHub Pages

## 🖼️ Cómo agregar imágenes

1. **Patrimonio Cultural**: Coloca las imágenes en `images/patrimonio-cultural/`
2. **Patrimonio Arquitectónico**: Coloca las imágenes en `images/patrimonio-arquitectonico/`
3. Las imágenes se mostrarán automáticamente en las galerías

Nombra los archivos como:
- `imagen1.jpg`, `imagen2.jpg`, `imagen3.jpg`, `imagen4.jpg`, etc.
